🔌 Arsitektur Klien-Server Terpisah

Aplikasi ini berjalan dengan Frontend murni (SPA) yang berada di direktori frontend/ dan berkomunikasi ke Backend Laravel API di port 8000 menggunakan HTTP JSON RESTful requests (CORS enabled).

⚡ Logika Dosen: Skenario 1 vs Skenario 2

Jika mapel ada di 1 tempat $\rightarrow$ Skenario 1 (Lokasi Tunggal Terpadu).
Jika mapel tersebar $\rightarrow$ Skenario 2 (Proximity Clustering Haversine).
